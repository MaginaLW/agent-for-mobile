# M0-4 发送相册最新截图

把手机相册中最新的一张截图发送给微信「文件传输助手」。（发给文件传输助手在站规白名单内，无需暂停。）

注意（apps.md）：微信无障碍树恒空，本任务预期依赖截图视觉定位，成本会高于纯 a11y 任务——这是 harness 成本复测的基准卡（M0 基准 $1.26 / 35 轮）。

已验证的高效路径（2026-07-17 实测）：打开系统「相册」App（a11y 树可用）→ 相册页找「截屏」→ 打开最新一张 → 分享 → 微信 → 文件传输助手 → 发送。**不要走微信内「+ → 相册」选图**：其「截屏」筛选下拉在本机点选后回弹（3 次复现，烧了 ~10 轮）。
