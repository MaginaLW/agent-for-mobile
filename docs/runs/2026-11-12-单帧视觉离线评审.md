# 单帧视觉方案离线评审

日期：2026-11-12。工作树基线 `9dd102a51e2e5e40f07b71c8fb70d29794ea16a2`。按用户“按照建议和串并联关系完成任务”推进[阻塞调查](2026-11-12-阻塞处理调查与收尾.md)提出的视觉评审。本报告是方案比较和评审结果，不修改现行视觉合同、验收判据或设备许可；没有新增图像、OCR、设备读取、输入、安装、权限或生产接线。

## 1. 结论与可决定事项

同一合成帧能把 pane、标题、消息视口、编辑区及可见遮挡的解释限定在同一个图像坐标域，减少从不同截图拼接视觉事实。它不能把像素候选变成原生窗口身份、可靠输入连接、可触达安全区或动作时刻的有效证据。当前既有能力不足以把单帧方案接入现行完整 T-L1/P0 链；这一结论没有因为模型初标成功而改变。

本轮形成两个可分别判断的方案，不能将第二项的成功充当第一项完成：

| 方案 | 交付与接受范围 | 本轮判断 |
|---|---|---|
| A：满足现行完整视觉合同，继续自动准备、输入、确认与后验 | 原生来源、身份、geometry、IME、遮挡、阶段有效性等全部有可验证来源；视觉只承担其能支持的语义识别 | 当前 NO-GO。标准截图没有所需联合来源；再采一张、补 metadata 或缩短 TTL 都不能解决 |
| B：独立的单帧只读感知研究 | 仅返回本图中区域的候选、不可观察项、歧义及拒绝理由；没有 action ref、输入坐标、目标准备记录或 T-L1 grant | 技术上可评估，有明确的输出与反例，见 §4；它是独立研究产物，不能解除 A 的缺口。现有单图初标已经覆盖一条窄路径，不应为重复这条路径重新采图或造框架 |

建议保留 A 的完整目标与所有未通过项。若要对 B 追加实现，先说明其具体消费者与本次要减少的未知，例如“同一图内列表同名项是否被误选为会话标题”；否则目前没有必要新增常驻视觉工具。A 下一步所缺的是可核验的来源能力或对保证范围的明确决定，而不是新的生命周期实现。当前不将合作接口视为已具备条件，也不推导所有未来来源均不可能。

## 2. 现行要求逐项比较

依据为[视觉合同 §3–§4](../specs/2026-11-01-平板window-pane视觉证据合同-design.md#3-必须形成的证据关系)。表中“可支持”均仅指像素或受控处理过程中的事实，不承诺模型识别必然正确。

| 现行证据关系 | 同一合成帧可支持什么 | 单帧不能证明什么 | 必须保留的拒绝边界 |
|---|---|---|---|
| 采集、会话与时钟 | 一次已绑定图像在受控内存中供多项解释消费，不把多个 buffer 冒称同一图 | 图像与树/IME 同代；compositor 实际采样时刻；时钟跨源可比；截图后状态 | 不由 caller 填相同 token 或时间来补同代；旧帧不续用 |
| display 与 geometry | 图像自身宽高、图内区域及像素域裁剪关系可检查 | 唯一物理 display、旋转、缩放、insets/cutout、图像到输入坐标的同代变换 | 图像坐标不输出为屏幕动作坐标；不默认零 inset 或 display 0 |
| 原生 window | 可以描述看起来分离的可见内容区 | OS 窗口数量、owner、原生 identity、窗口替换或连续性；同包多窗如何绑定 | 不按包名、左右位置或同 bounds 跨源认同；unknown 清单项不忽略 |
| 唯一 conversation pane | 可提出视觉 pane 候选，并报告多个或不可观察 | 已绑定原生 window 内的唯一 conversation 身份及跨阶段连续性；同名会话真实对象 | 多个候选不择一猜测；只有标题或位置不足以建立准备证据 |
| title/message/editor 区域 | 可在同图内提出相互关系，区分列表行、标题、编辑区与消息视口的视觉角色 | 语义真值、完整可见性、区域同 native geometry/epoch；空白视口是否全量无消息 | 不把不清晰当 ABSENT；输入回显不是消息；初标不是独立真值 |
| 裁图与 OCR | 以图内 pane 候选为范围时，可检查裁剪包含、退化、越界及图内 X/Y 变换 | 原图到原生 window、pane 到屏幕的来源关系；OCR 置信度不自证身份 | 不复用手机比例/像素带；未绑定的图内裁剪只供研究，不进入现行消费 |
| IME 与确认 surface | 可报告键盘、卡片和按钮是否在图上可见，标出可见遮挡的疑点 | 键盘实际 mode/binding/editor、透明触摸拦截、卡按钮可触达、整屏之外的遮挡 | 没有键盘像素不判 hidden；看见“允许”不等于真人批准或可触达 |
| epoch、阶段与有效期 | 同图内的视觉部分不需另外拼接采集代 | 拍图后布局不变、事件覆盖完备、跨阶段 TTL、确认后到动作前的连续有效性 | 不新造 epoch 或阈值；漂移/未知停止，旧批准不复活、不自动重弹 |

因此，把原生 inventory 改作“旁路守卫”仍不能跳过 unknown、IME、身份或几何要求。像素没有发现异常，也不能作为旁路守卫从未漏报的证明。只读感知若与原生材料冲突，可以记录冲突并拒绝下游，但不能用图像覆盖该材料。

## 4. 最小只读感知验证方案（建议，未生效）

若后续决定需要 §1B，最小用户结果应是一张已获相应授权图像的可解释报告：哪些内容可见、哪些区域只是候选、哪里存在歧义、为什么没有生成可执行目标。无需新增网关工具、权限、后台进程或通用 schema；先复用现有研究展示及四类区域定义，输出留在相应本地研究材料中。

建议的一条最小验证链如下，本轮只设计，没有执行或暗示已取得图像运行许可：

1. 固定候选、图像输入范围、消费者、保留方式及外发目的地。先检查输入来源和处理范围；缺失时在识别前拒绝，不自动重新采图、切通道或上传。历史帧许可只覆盖原处理范围，不继承为新研究持续许可。
2. 仅在同一不可变图像实例上识别 pane 候选，再在其内部提出 TITLE/MESSAGE/EDITOR；明确图像坐标域。不借多次 OCR 结果或旧图补齐缺失区域，不创建 action ref、屏幕坐标、prepared target 或批准。
3. 分别记录“可见候选”“图内未见”“不可观察/有歧义”；其语义暂不等同既有 `ProbeRegionState.KNOWN` 的生产可信证明。不含真实标题/消息的公开交付仅记录结果类别与限制；图像、坐标、原生标识及内容 hash 不入 Git。
4. 与独立于该次模型输出的参考标注比较；没有独立参考时，只能交候选与不确定性，不宣布正确率或语义验收通过。参考标注可来自受控合成图或自有靶标，但这只证明该样本，不能外推真实微信/原生窗口。
5. 必须观察到以下反例对应的拒绝或降级结果。对于像素根本不能区分的情形，不要求模型猜出不可见真值，而要求报告和消费边界承认不可证明，动作链保持不可达。
6. 关闭输入及展示资源，分别报告实际释放与未知清理。处理/清理失败只记录，不自动重试或生成设备恢复动作。

不预设 IoU、置信度、TTL 或误识率数值；这些数值没有当前代表性语料及风险依据。本轮单图不能推导质量门槛。前四步即使通过，也仅证明只读研究产物，现行 T-L1/P0 仍逐项验收。

### 可复核的反例与预期结果

下表是本次离线纸面推演，未创建或运行图片 fixture；它给出后续最小覆盖，避免拿格式检查代替实际视觉结果。

| 反例 | 研究报告应有的结果 | 下游必须保持的行为 |
|---|---|---|
| 桌面或应用列表，无会话内容 | 图中四类会话区域未见；不能断言系统没有后台窗口 | 不建立目标；既有 P02 文字记录仅是此窄类实例 |
| 同名文本只在左侧列表，右侧标题不同/不可读 | 左侧列表行不作为目标 TITLE；右侧不确定分别记录 | 不靠全屏命中或 Y 坐标选会话 |
| 两个同名会话或两个完整 pane 候选 | 保留两个候选并说明歧义，不按位置/焦点猜选 | 不建立唯一目标 |
| 目标 pane 边缘/标题/编辑区被截断，或分隔把手相交 | 说明部分不可观察或可见遮挡疑点；不能靠补全猜完整区域 | 不输出完整性、安全区或可触达结论 |
| 消息视口空白；marker 只在编辑区 | 分别报告可见空白与编辑回显；不推断历史消息全集 | 不作发送成功或未发送证明，不重发 |
| 无键盘像素，但 IME mode/binding unknown | 图内未见键盘；系统 IME 仍 unknown | 不判 hidden，不放行输入 |
| 透明拦触层，或截图外的输入连接指向别窗 | 单帧无法区分，显式列为不可证明 | 不能以“无可见遮挡”放行动作 |
| inventory unknown、缺失或与图像冲突 | 原生缺口保留，图像结果只能附记候选/冲突 | 不以视觉覆盖来源拒绝 |
| 拍图后窗移动/旋转/被替换，旧图外观未变 | 本帧解释不含“当前仍有效”的承诺 | 不续用坐标、准备证据或旧批准 |
| 两张图尺寸/token 看似一致，但区域混用 | 不拼接成单帧报告；来源不足时拒绝 | 字段一致不补同代或 identity |
| 卡片及允许按钮像素可见，但触达与真人决定未知 | 仅报告像素存在，不报告已批准 | 危险动作仍须设备端 ConfirmOverlay 的本次真实回调 |

## 5. 接力与停止点

本轮已完成要求关系比较、可复用实现核对、两种保证范围的明确区分、只读验证建议及反例。尚没有执行视觉测试、新图像识别、来源实测或 T-L1 验收；没有未完成测试被写作通过。

现行 A 链缺少可核验来源，不能进入完整 producer/schema、执行候选或新真机卡；没有可通过本轮纯离线编码直接解除的来源缺口。不新增一个恒拒绝的适配器或 metadata 外壳来充当进展。B 若没有具体新增研究问题，也不重复 S04/P03 或新增人工画框任务。S05 原候选保持可选、未消费，旧冻结轮不重跑。

此停止点只约束视觉依赖链。R5 验收范围评审及不依赖视觉的已授权离线工作可并行推进；后续 P0/T-L2/生产接线按各自真实前置，不能因本报告完成而放行。需对合同保证范围作决定时，应展示具体差异与残余风险，由有权决定者处理，而不是把替代研究默认当成完整产品目标。

经验沉淀：本轮新增的可复用源码事实是 `validProbeReview` 验格式而非语义、`FreshVisionSession` 验本地 revision 而非跨源原子性。适用条件、有效做法与核对依据已并入 §3；未新增 ROM 有效性结论，也未改全局记忆。
