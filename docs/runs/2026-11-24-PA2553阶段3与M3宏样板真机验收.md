## 3. 分阶段实测结论

### 3.1 Step 1：冷态拉起根因与 PR #86 无障碍重绑回归

1. **冷态后台拉起拦截证据**：入场时 `dev.magina.gateway` 进程未存活、`GatewayA11yService` 位于 `Crashed services`、`GatewayService` 为 `absent`。`dispatch-profile.ps1` 依次执行 `am start-foreground-service`（受 `exported="false"` 拒绝）与 `run-as dev.magina.gateway am start-foreground-service --user 0`（返回 `Error: Not found; no service started.`），`dumpsys activity services` 出现 `app=null`、`mAllowStart_noBinding=DENIED`、`getFgsAllowStart=DENIED`。
2. **标准前置链生效**：执行 `am start -n dev.magina.gateway/.MainActivity` 再 `run-as dev.magina.gateway am start-foreground-service --user 0 -n dev.magina.gateway/.GatewayService` 后，`GatewayService` 立即进入 `isForeground=true`。不改变 `dispatch-profile.ps1` 的后台预检策略，避免干扰已切好前景 App（如横屏微信）的任务。
3. **无障碍重绑与基线还原通过**：`r3-script-bt-readonly-20261124-r2` 预检触发非 `com.android.settings` 前台有界 toggle 重绑后，独立核对 `dumpsys accessibility` 显示 `Bound services` 同时包含 `vivo输入法` 与 `执行网关`、`Crashed services:{}`，且 `enabled_accessibility_services` 完整保留前导 `:` 与 `AutoSendImageService`。

### 3.2 Step 2 & Step 3：APK 升级、新版工具面与淘宝只读

- **升级核验**：停止旧版 `GatewayService` 后执行同签名 `adb install -r`，现场用户点击 `PackageInterceptActivity` 确认完成升级，设备端 `sha256sum` 与候选 Debug APK 逐字一致，三项运行时权限（`POST_NOTIFICATIONS`、`BLUETOOTH_CONNECT`、`READ_MEDIA_IMAGES`）与 `SYSTEM_ALERT_WINDOW` 仍为 `granted=true`。
- **Step 3A 工具面核验**：新版网关报告能力位 `a11y` 与 `ocr`；`skillpack_lookup(app="设置")` 返回包含 `BLUETOOTH_SETTINGS` 失败后改用主设置 UI 导航兜底说明；`skill_macro_list()` 返回 `xhs_search_prepare`，状态为 `candidate_unverified`。
- **Step 3B 淘宝只读查物流**：进入全部订单页后定位到最近一笔已显示「交易成功」的实体订单，执行器两次点击「查看物流」均回到订单列表而未呈现物流详情页，按站规单轮报 `reported-fail` 停止，不重试。核验后前台停留在 `com.taobao.taobao`。
