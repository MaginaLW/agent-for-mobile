# 无障碍 overlay 确认卡离线实现

日期：2026-11-10（Asia/Singapore）。分支 `codex/gateway-a11y-overlay`，代码提交 `885f4af`，基于 `b6ef47c`。本轮只做离线实现、测试和构建，未安装 APK、未连接/修改设备、未推送。

## 改动

- `ConfirmOverlay.ask` 新增可选 `ConfirmOverlayWindowHost`。当 `GatewayA11yService.instance` 可用时，`ToolRegistry` 传入无障碍服务上下文，确认卡使用 `WindowManager.LayoutParams.TYPE_ACCESSIBILITY_OVERLAY`；无障碍服务不可用时回退原有 `TYPE_APPLICATION_OVERLAY`。
- 两种窗口都保留 `FLAG_NOT_FOCUSABLE | FLAG_NOT_TOUCH_MODAL`，不改变确认卡绘制、首帧取证、按钮启用、通知/拒绝共享裁决和清理路径。
- 通知仍只有“拒绝”和“查看详细”，没有增加通知“允许”；`ConfirmDecisionReceiver` 对 `allowed=true` 继续 fail-closed。
- 无障碍 overlay 仍属于网关自有非应用窗口；新增 `AccessibilityWindowInfo.TYPE_ACCESSIBILITY_OVERLAY`（type=4）排除用例，避免进入快照/ref/动作面。
