## 四项证据的可行性

| 必需证据 | 无日志正文的设备元数据能核定什么 | 仍缺什么；何时才可继续 |
|---|---|---|
| 唯一请求关联 | 工具和缓冲区存在与否 | 不能把 audit_id 对上系统启动事务。相近时间、同包名或现成 Activity token 均不足以自动建立一对一关系；须先确定实际系统字段及关联方法。 |
| 独立系统接收 | system/events 缓冲区是否可查询容量 | 容量可读不证明请求事件会输出、正文可读或本次请求被接受。须另核定限域取证、字段语义及实际正向事件；shell `am start` 身份不同，不能代替应用调用。 |
| 实际窗口起止 | 现有元数据不能导出应用内部窗口 | 既有响应/审计不足。可另评估最小观测候选；如果未来独立来源能完整覆盖且可证明包含实际窗口，也可审查这一保守覆盖方案，不能仅凭宿主调用时长宣称已覆盖。 |
| 完整覆盖及丢失检查 | 缓冲区容量与工具选项 | 无法证明窗口内事件完整。环形缓冲、编译/属性/应用/显示过滤，以及采样间隙都须处理；零事件、零散快照或重复查询容量不能证明目标未落地。 |

四项必须共同成立。补应用计时最多解决可观测窗口的一部分，不能把被测组件自报变成独立系统证据。

### START 与 WM/transition 的联合字段复核

同一固定提交进一步读取四个必要文件后停止：[`windowmanagertrace.proto`](https://android.googlesource.com/platform/frameworks/base/+/99b01a65cc4c104933788b3143285ab6bae65827/core/proto/android/server/windowmanagertrace.proto#48)只有采样时刻、来源位置和 WM 状态；[`windowmanagerservice.proto`](https://android.googlesource.com/platform/frameworks/base/+/99b01a65cc4c104933788b3143285ab6bae65827/core/proto/android/server/windowmanagerservice.proto#356)的 Activity/window 标识和 `proc_id` 对应实例/活动进程，并非本次发起请求；[`windowmanagertransitiontrace.proto`](https://android.googlesource.com/platform/frameworks/base/+/99b01a65cc4c104933788b3143285ab6bae65827/core/proto/android/server/windowmanagertransitiontrace.proto#48)有 transition ID、start/finish transaction ID 和 layer/window，但标准 START 文本没有这些键，不能把 transaction 名称当作 Binder 事务 ID。

[`IActivityTaskManager.aidl`](https://android.googlesource.com/platform/frameworks/base/+/99b01a65cc4c104933788b3143285ab6bae65827/core/java/android/app/IActivityTaskManager.aidl#95)的 `startActivity` 返回启动结果 `int`，没有请求句柄、目标 ActivityRecord/transition 或 Binder transaction ID 出口。因此，**当前标准 START + WM/transition 字段组合 NO-GO**：没有已证实的一对一请求桥接链。给 App 增加调用编号、PID/TID、dispatch/wait 单调起止只补自身窗口，仍需系统侧同键或经过验证的关联链；不先实施这些观测来假装解除了系统来源阻塞。此结论只针对现有字段组合，不证明所有可定制系统观测永远不可行。

WM 层级的 name/title 有 `DEST_EXPLICIT` 隐私标记；它不证明自动脱敏。当前数据源配置未找到按本次请求/包/user/display 限域收集的现成字段，不能以只采可见元素或低频 FRAME 替代隐私边界，也不建议先采全系统再筛。后续只有请求桥接、实际覆盖和源侧限域均有具体方案时才继续；ROM 能力仍 UNKNOWN，不新增 trace、Intent 或设备运行。完整公共源码增量留本地忽略报告 `.checks/followup-20261112/r5-joint-source-contract.md`，没有读取任何设备材料。
