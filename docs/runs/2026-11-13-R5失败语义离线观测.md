## 实施与验证

三个现有源码文件与一份专项测试已完成：`ToolRegistry.kt`把debug观测保存在调用内CallScope、显式传给intent_send并复用统一audit note；`IntentTools.kt`保留公开5参入口，将实际分派/后续终态共用窄执行链；`SystemTools.kt`保留原轮询逻辑并让生产与测试共用同一poll函数。没有新模块、依赖、Provider或工具接口；不让观察器改变业务结果、替换原异常或自动重发。

debug审计note追加 `;r5_observation=` 后的有限JSON，版本1；字段为available、pid、process_instance、audit_id、dispatch及其进入/正常返回单调时刻、poll及起止时刻、checks。进程实例由本进程惰性UUID生成，audit_id与该次Envelope及审计行共用；release或其他工具的工厂直接关闭，连PID/UUID求取也不执行。未触达、no_target、no_a11y、hit、timeout和interrupted分别保留，checks只计已完成读取；观察器时钟/写入失败使结果不可用，不补成timeout。note缺失或不可用必须作为未验证，不从整次audit耗时倒算实际轮询窗口。

专项实际调用生产共享的分派→poll→既有finish→Envelope/Audit链，首次Debug运行 **9 tests / 0 failures / 0 errors / 0 skipped**，Gradle exit 0、约66秒。覆盖只分派一次的超时、no_a11y、门前未触达/无目标、正命中提前返回、分派异常有限分类、读取中断、观测时钟失败不改业务结果、并发隔离及关闭工厂。日志、XML稳定副本和四文件/日志/XML收据在 `.checks/r5-observation-20261113/`；已核与受审文件一致，避免后续完整门覆盖build目录后失去专项证据。

独立静态审查无阻断发现，检查同次audit关联、原参数/错误/轮询及release关闭边界。专项不实例化真实Android Context、不经MCP socket；ToolRegistry接线目前只有源码审查，不能写成整个Android runtime已验。进程终止、致命Error或审计I/O失败可能没有终态note，仍记缺证，不当作未分派或超时；现有Audit.args隐私范围也不由本候选解决。

当前Release、完整统一门及真实Android路径尚未验证；本轮没有发出真实Intent、连接设备、安装、开权限或生成真机卡。后续只在已有授权和准入可核时补相应证据，不以自有靶标正例代替原第三方强负例。
