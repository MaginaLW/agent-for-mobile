## 3. 首轮失败根因、选择器收窄复测（`c4ae700`）与双宏转正决定

- **首轮失败根因**：`final_snapshot` 显示淘宝首页底栏同时存在 `role=button, desc="我的淘宝", flags="C"` 与子节点 `role=text, text="我的淘宝", flags=""` 两个匹配节点；`ui_find(text="我的淘宝")` 返回 `OK`（2 条匹配），因非唯一匹配未绑定 `save_ref="my_taobao"`，导致 `open_my_taobao` 触发 `skip_if_ref_missing` 被跳过，界面停留在首页，后续 `find_all_orders` 返回 `E_NOT_FOUND` 并同样跳过 `open_all_orders`。宏本身返回 `completed`，Codex 按规未盲点并如实上报失败（`reported-fail`）。同时核查「我的淘宝」页订单入口真实节点为 `role="button", desc="我的订单全部", flags="C"`（同页另一含「订单」按钮为 `desc="订单评价"`），而哔哩哔哩「暂不开启」推送提示弹出时 OCR 融合亦可能双产出 `role="button", text="暂不开启"` 与 `role="text", text="暂不开启"`。
- **候选修复与复测冷态起服（`c4ae700`）**：
  - `taobao_orders_prepare.json`：`find_my_taobao` 改为 `{"role": "button", "desc": "我的淘宝", "scroll_search": false}`，`find_all_orders` 改为 `{"role": "button", "desc": "我的订单", "scroll_search": false}`；
  - `bili_readonly_feed_prepare.json`：`find_dismiss_push_prompt` 改为 `{"text": "暂不开启", "role": "button", "scroll_search": false}`，复测前按诚实门槛暂置 `verified: ""`；
  - 新 Debug APK（`fb317cde1ebed31a108850784d6ef25b77776114b1274ab29fcb24faf47e9693`，同签 `dd7b4fc75510da73b17ed9aec1864ff4b4236fe3c83f79f95bc23f1d930db6c3`）经 `adb install -r` 覆盖安装并核验 `sha256sum` 与 4 项权限（`granted=true`）后，`bootstrap-gateway.ps1 -ReturnHome -Json` 再次验通冷态起服（`Ok=true`、`Status=cold_started`、`ColdStarted=true`、`ReturnedHome=true`、`ServiceState=foreground`，`Accessibility` `leading_colon=true`、`gateway_enabled=true`、`gateway_bound=true`、`gateway_crashed=false`）。
- **转正决定**：
  - `taobao_orders_prepare.json`：复测 `m3-taobao-orders-promote-r2-20261126` 1 轮 `25s / 52,530 in_tok` `success`，11/11 子步全 `OK` 并直达淘宝「全部订单」页，0 ConfirmOverlay，正式晋级 `"verified": "2026-11-26"`；
  - `bili_readonly_feed_prepare.json`：复测 `m3-bili-feed-promote-r2-20261126` 1 轮 `32s / 113,317 in_tok` `success`，0 ConfirmOverlay，正式恢复/转正 `"verified": "2026-11-26"`（注：两轮实测中「暂不开启」推送弹窗均未自然弹出，弹窗实际弹出时的 `role="button"` 命中分支待后续自然复现时补充观测）。
