## 关键发现（→ M1 需求清单）

1. **深链在 OriginOS 上不可靠**：`am start -a android.settings.BLUETOOTH_SETTINGS` 没把蓝牙页带到前台（主设置 intent 正常）。M1 的 `open_link` 工具要有「深链失败 → UI 导航兜底」逻辑。
2. **系统状态验证不能信 settings 键**：`settings get global bluetooth_on` 返回 0 时蓝牙实际是开的（Android 16）；`dumpsys bluetooth_manager` 才是真值。M1 的验证通道要用 dumpsys/专用 API。
3. **vivo 品牌开关实测确认**：「USB 模拟点击」开了之后注入完全正常，runbook §1.1 的矩阵有效。
4. **`uiautomator dump` 在重动画商业 app（京东首页）会报 could not get idle state**——设置类 app 正常。截图+视觉定位兜底通道是刚需，不是可选项（本轮京东任务全程视觉定位完成）。M1 自研执行器用 AccessibilityService 直读事件流可以绕开 idle 等待，这是自研的核心价值证据。
5. 京东全程无风控/无验证码弹窗（USB 调试 + 注入未被电商 app 拦截）；开屏无广告（可能因为是老用户/直接 monkey 启动）。
6. 「更多」弹出菜单里藏着「删除订单」这类危险项与「查看物流」相邻——M1 确认层的「危险控件识别」要覆盖弹出菜单场景。
7. **App 内 scheme 深链价值实证**：小红书 `xhsdiscover://search/result?keyword=<urlencoded>` 一步直达搜索结果，把「点搜索框+中文输入」整段消掉——App 技能包（每个 app 的深链清单）是真金白银的降本手段。系统设置的 intent 反而不可靠（发现 #1），结论：深链要按 app 逐个实测建库。
8. 小红书返回列表后 feed 位置精准恢复，多步「进详情→返回→进下一条」模式可行；注意详情页图片区双击=点赞，agent 必须单击（只读纪律）。
9. **devicekit 中文输入在 vivo/Android 16 上失败（可复现 3 次）**：输中文时输入框出现的是剪贴板旧内容——「写剪贴板+粘贴键」机制被后台剪贴板写入限制拦截。纯 ASCII 正常。**M1 必须自带 IME 通道（输入法级注入），不能依赖剪贴板戏法。**
10. **微信的无障碍树为空**：`mobile_list_elements_on_screen` 在微信内始终返回空，只能截图+视觉定位。另有输入法预测引擎篡改大小写、软键盘弹出导致坐标错位（引发 2 次误触，其中一次点开了聊天内敏感文件）。→ M1 需求：键盘状态感知、敏感对话/文件黑名单、点击前二次校验。
11. **headless 编排链路可用**：`claude -p --output-format json --allowedTools "mcp__mobile"` 从主会话派 agent 干活成立，JSON 自带精确 token/成本/轮次；坑：headless 不信任工作区时忽略 settings.json 的 permissions.allow，用 `--allowedTools` 旁路（或接受一次信任对话框）。这条链路就是 M2「手机上 Termux 跑大脑」的原型。
12. **成本实测（重要校准）**：设置/京东/小红书类（a11y 或深链可用）便宜；**微信类纯视觉任务 $3+/任务**（75-111 轮，每轮带截图），比 design note §5 的 $0.15-0.5 估算高一个数量级。Pro 的 $20/月 Agent SDK 额度只够 ~6 个微信级任务——**深链库、宏回放、树优先不是优化项，是可行性前提**；重度使用需 Max 档或路由到便宜模型。

## 结论（M0 完成，2026-07-16）

- **概念成立，M1 立项。** 手机侧全链路（授权/截图/注入/UI树/装APK）、LLM agent 循环（树/视觉定位→操作→验证）、headless 编排链路（claude -p + mobile-mcp + --allowedTools）全部跑通。
- **M1 硬需求清单（按优先级）**：① 自带 IME 通道的中文输入（devicekit 剪贴板方案在新 Android 上已死）；② 截图+视觉定位为一等公民（微信 a11y 树为空、京东 dump 超时）；③ 深链库/技能包（小红书深链一步顶十步）；④ 敏感对话与文件黑名单 + 点击前二次校验（实测发生 2 次误触）；⑤ 键盘状态感知（坐标错位主因）；⑥ 降本机制（宏回放/树优先/便宜模型路由）——纯视觉任务 $3+/个，Pro 额度撑不住裸跑。
- 任务 2 的中文输入遗留项：等 devicekit 修复 / M1 自研 IME 通道后复测。
