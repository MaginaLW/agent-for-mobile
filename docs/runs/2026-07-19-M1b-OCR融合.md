# M1b OCR 融合层 · 开发与真机验收（2026-07-19）

> 设备：vivo V2352A / Android 16 / OriginOS 6 / 1260×2800。验证方式：网关 HTTP 零大脑 smoke（adb forward + Invoke-RestMethod，不烧订阅 token），微信真页，全程不点「发送」零副作用。构建 8 轮迭代（bug 全在真机 smoke 中暴露）。

## 交付内容（app/gateway）

- **OcrEngine**（新增 `ocr/OcrEngine.kt`）：ML Kit bundled 中文 16.0.1，client 常驻保热加载；conf<0.5 过滤（整屏）；`norm()` 归一（全角/大小写/o→0）供匹配。
- **ui_snapshot 自动融合**（spec §5.4）：前台**活动应用窗口**（type=APPLICATION && isActive，不用包名比对）可读元素 <5 时触发整屏 OCR；a11y 骨架 + 中心包含且面积同量级（≤12×）挂载为 `fused`、内容相同去重、其余落独立 `ocr` 元素（ref=oN）；返回带 `fusion/fg_elements`。整屏 OCR 缓存 = revision + **2s TTL**，手势后主动失效。
- **OCR ref 操作链**：`resolve` 对 OCR ref 做点击前二次校验（目标邻域重截重识：裁剪 ≥620×220、conf 阈 0、归一 contains ∥ 位置稳定+字符袋相似度 ≥0.4，bbox 随最新命中微调）→ `dispatchGesture` 点击/长按；**手势滚动** `gestureScroll`（ui_find scroll_search 无 a11y 列表时的翻页兜底 + ui_action(scroll)）。
- **type_text 修复 + OCR 读回闭环**（spec §8）：SET_TEXT 假成功（报 true 读回 null——微信搜索框实锤）时**也降级 IME**；最终读不回用 `ocrReadRegion` 裁剪读回验证（channel 带 `+ocr` 后缀）；OCR ref / 树空无焦点时走 `typeTextNoNode`（IME 盲注 + OCR 读回）。
- **感知面**：`wait_for(text_appears/text_gone)`、危险词上下文 `screenTexts()` 在前台稀疏时并入 OCR 文本（归一匹配）。
- **杂修**：media_query 权限预检（MediaStore 无权限静默空游标 → 显式 E_PERM_MISSING）；内部视觉通道截图吸收 E_RATE_LIMITED（硬节流实锤，等 900ms 重试一次）。
- APK 10.8MB → **59MB**（bundled 中文模型，spec §9 预估 20–40MB 的上限外一点）。

## 真机验收（smoke4 全绿）

选择页（ShareImgUI）链路：`ui_snapshot` fusion=ocr **17 OCR 元素** → `ui_find(知足常乐)` → `ui_action(click)`（校验+手势 1.2s）→ **发送确认弹窗弹出** → 弹窗 OCR 读出（发送给/取消/发送）→ `ui_find(取消)` → click → `wait_for(text_gone=取消)` met → back/home。聊天列表页融合 **31 OCR 元素**（含「文件传输助手」文本精确）。回归面：设置页 fusion=none/fg=43（不过度触发）、网关主界面 fusion=none/fg=9。

## 首跑抓修 4 个真 bug（全部真机暴露）

1. **fg 归属按包名不可靠**：vivo 系统窗口事件污染 fgPackage（设置页 43 节点被判 fg=0 误触发 OCR）→ 改「活动应用窗口」归属。
2. **悬浮节点误吞 OCR 行**：充电胶囊等带文本大 a11y 节点几何罩住页顶，「选择聊天/搜索」被按包含关系判重丢弃 → 去重改「内容相同」判。
3. **CJK 形近抖动误报 STALE**：同一搜索框两帧识别「搜素/搜索」互跳 + 放大镜偶识为 Q，纯 contains 校验失败 → 位置稳定+字符袋相似度容忍分支。
4. **SET_TEXT 假成功不触发 IME 降级**（最重要，spec §8 核心）：微信搜索框 SET_TEXT 报 true、读回 null，旧逻辑直接信任返回 verified=false，IME 通道未上场 → readback==null 一律降级。

另发现：小裁剪图 OCR 塌方（372×147 → 0 行）、截图节流存在硬报形态、深色灰字占位符漏识 ~40%、`install -r` 重置运行时权限且 a11y 需 toggle 重绑、**网关后台启动三方 app 被 vivo/Android16 BAL 拦**（设置放行、微信不落前台、shell 可绕）——已归档对应 knowledge 册。

## 遗留

1. type_text 的 IME+OCR 读回腿**代码就绪未真机闭环**（留言框占位符深色漏识未点上；随 IME 自动切换一并验，或任务 2 会话页流验）。
2. 「文件传输助手」不保证选择页首屏（本机当前列表状态实锤）→ 大脑侧策略：find 短子串+scroll_search，或搜索框通道（占位符识别要 TTL 重试）。
