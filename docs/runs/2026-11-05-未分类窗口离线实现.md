## 实现行为

成功 type getter 的 signed Int32 原值不再因原项目 0..255 范围而丢弃；1–7 保持原映射，其余为 unknown。getter 仍一次，之后继续原 shell/root 读取，其他字段失败按原阶段丢弃。unknown 不进入应用标题匹配、pane/语义树，也不参与可信焦点或 IME 隐藏推断。

新 observation 为 `tablet-layout-observation/c1b-v2`，provenance.version=c1b-v2；外层为 `tablet-c1b-inventory-result/v3`，保留 12 个首次停止键，强制 type invalid 首停为 0、拒绝频次表为空。原值已直接保留，无需冗余聚合。同名 observation 诊断 reason 仍表示 unknown/错误映射，不能与丢弃首停次数互相恢复。

原 c1b-v1、inventory v1/v2 schema 与历史 fixtures 不变。新旧入口共享语义内核，通过固定版本参数区分；旧公开 API 默认仍为 v1，无临时全局版本切换。当前 runner 精确绑定新封套/inner，保留原隐私、原文字节/T0/producer 绑定、失败留证和一次消费顺序；收据仍为 tablet-c1b-run/v2，以 result_schema 区分。
