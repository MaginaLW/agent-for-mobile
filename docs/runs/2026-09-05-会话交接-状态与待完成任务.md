## 2. 下一步唯一主线：r14 preflight（勘察已完成，可直接动手）

### 2.1 它和 r12 的本质区别

r12 是**换常量**；r14 是**加新逻辑**。而且 preflight 渲染器不走模板——它拿**上一轮的 leaf**
当源做增改：r13 拿 `preflight-690693a-r11.ps1`（277697 B）做 3 次精确替换 + 1 次约 630 行大块插入，
产出 300938 B。所以 r14 的源是 `preflight-a661f36-r13.ps1`（300938 B / 6550 行 / `bf15d009…`）。

### 2.2 插入点（已定位，结构上很干净）

| 对象 | 位置（在 r13 leaf 内） |
|---|---|
| 四次只读 Git 调用 | `rev-parse --show-toplevel --absolute-git-dir`(2189) · `ls-files -v --stage -z`(2205) · `status`(4834) · `ls-files --modified --others -z`(5636) |
| 统一入口 | `Invoke-ReadOnlyGit`(1233–1613) |
| 主 try | **1839–5757**，catch 5701–5703，**finally 5704–5757** |

四次调用**全部落在主 try 内**，所以：前置挂在 2189 之前、后置挂进已有 finally，
天然满足「前置不过不启动 Git、后置即使 Git 失败也执行」。

### 2.3 一处必须照惯例的设计判断

**后置在 `finally` 里不能 throw**，否则遮蔽 primary。leaf 里已有现成惯例——
`$gitRootExitNotObservedCount` 在流程中累加、由终态汇总断言（6044 行）。
后置检查照抄这个惯例：**finally 里只记结果，终态汇总里判死**。

### 2.4 可复用的原语（不要另起平行实现）

leaf 自带 `TL1C1bPreparedNotAuthorizedFileIdentityV1::Read()`，直接给出
`LinkCount` / `FileAttributes` / `FileSize` / `StableId`——正好是信任树核验需要的四样；
另有 `OpenFileReadNoFollowDenyWriteDelete`、`EntryExistsNoFollow`、`Assert-Preflight`、`Assert-Identity`。
冻结值即 `9576` / `4c5e585b…7458` / `9489` / `85`（2026-09-02 已复核本机可满足）。

### 2.5 渲染器写法

比照 `render-preflight-r13-a661f36.ps1`（106204 B / `962ee280…`）的
`Set-R13ExactText` / `Add-R13ExactBlock`（均带基数断言）+ AST 校验 + 残留 token 扫描。

**⚠ 常量块必须按变量名重写，不能全局字符串替换**：本轮的 `$expectedHelperSha256` /
`$expectedLauncherSha256` 在下一轮要变成**历史**那两个常量的值，全局替换会同时改掉两者，
产出一个看起来完全合理的错误渲染器。

① 写信任树核验块 → ② 接前置/后置/终态断言 → ③ 造 r14 渲染器 → ④ 跑 + 静态复核。

## 6. 本轮新增的判据纪律（已进 [harness.md](../knowledge/brain/harness.md)）

1. **漂移门报警后先分「新增 / 修改 / 缺失」**——三者恢复路径完全不同，重装只治「修改」。
   更一般地：**恢复手段本身也需要一次对照**，先问「这个手段作用在哪个对象上、能不能让判据回到冻结值」。
2. **`exit 1` 至少要分「跑了并失败」和「根本没跑」**。`check.ps1` 声明 `#Requires -Version 7.5`，
   本机默认 `pwsh` 是 7.4.19，会在执行第一行前被拒、一个检查都不跑却同样 exit `1`。
   判据是汇总表出现过没有。**跑仓库脚本一律用钉定 7.6.4**
   （`~/.cache/codex-runtimes/codex-primary-runtime/dependencies/native/powershell/pwsh.exe`，`db6dd811…458f`）。
3. **待办条目写的「必须解决」要先落到具体文件行号**，落不下去说明描述本身要先修。
4. **「某字符串不在日志里」必须先证明该日志能被检索到已知在场的字符串**（对照先行）。
5. **`NotSigned` 在 MSYS2 载荷目录里是常态不是信号**；且 `-Content` 与 `-LiteralPath` 是两条不同的验签通道。
