## 下一离线步骤

`AndroidTabletC1bSource` 的 display 边界先调用 `service.display`，只有返回 null 时才执行默认 display 回退。
Android 官方 [Context.getDisplay 合同](https://developer.android.com/reference/android/content/Context#getDisplay())
说明未关联 display 的 context 可以抛 `UnsupportedOperationException`；现有写法不能进入此异常的回退。
这是源码已确定的合同缺口，但当前失败 payload 不保留调用点或异常栈，尚不能确定本机具体哪个 API 抛出异常。

保留 security/其他异常传播、默认 display 和尺寸/窗口一致性门。冻结的 `c43652a/r1` 和旧证据不修改；
