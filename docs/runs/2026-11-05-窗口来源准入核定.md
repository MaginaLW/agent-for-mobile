日期：2026-11-05（Asia/Singapore）。协调基线 `66763424dc895e2c0b7784e792e491f4421c4d9e`；输入是固定 `abb7b0d9ca99034e4e7886694fdd96c58082985c` 的[既有真机记录](2026-11-05-未分类窗口真机验收.md)与原封套/observation。本阶段只读复核存量证据和源码，未操作设备、签名、采图或创建运行卡。

## 交付与结论

完成交接要求的 unknown/IME 与 window/pane 图像来源边界核定，并将后续隔离端侧展示方案补入[既有来源设计 §7](../specs/2026-11-01-平板图像来源可行性-design.md#7-11-05-完整清单后的来源准入复核)。没有发现需要修复的 unknown/IME 门禁缺陷；不以补映射、忽略系统壳或重复采集旧路径解阻。

串行链为：核对固定输入 → 两路独立只读调查（unknown/IME、视觉来源与资源所有权）→ 主 A 整合真实几何与准入结论 → 文档及原门禁检查 → 本地提交。共享状态与知识由主 A 写入，来源设计由视觉调查代理单独更新；无并行构建或共享设备调用。

本阶段的实际结果是明确后续能实现什么、必须继续阻断什么。受限来源探索可以研究单个原生窗口的图像归属和现场结构，不需要先声称它是唯一 conversation pane；但仍须独立的制品/展示/隐私边界和新的设备准入。生产视觉 producer、机器合同、自动 pane、严格同代与 T-L2 的前置没有成立。

## 下一实现的具体边界

现有 debug lifecycle 只交元数据，完成通知前已关闭 buffer，不能直接用于端侧看图。C1b APK 禁止截图能力，不扩大其白名单。后续推荐独立 applicationId 的只读探针和仅本地展示入口，先核定像素借用、软件 Bitmap 的唯一持有者、取消/退出/迟到回调的释放与最小留存，不复用 gateway 的动作、OCR、网络或生产入口。

来源设计已把“每次唯一原生请求目标”与“唯一 conversation 目标”分开：存量脱敏标签不能恢复原生 ID；未来请求须从当次完整清单、同一服务实例中取得 exact 目标。unknown/IME 状态持续随探索报告保留，不授予 hidden、无遮挡、pane 或执行结论。人工区域标注只作后续识别需求的参考真值。

下一可独立离线实现的是未接线的内存借用/展示所有权组件及有意义的资源反例；这不等于可验收的端侧展示。独立制品、入口和展示生命周期仍须实施及隔离检查，真实图像归属/坐标/现场结构须另行获准取证。三问、最多四次未来单次请求仍只是范围候选，没有新增 C 队列、签名或设备许可。

## 验证与收尾

本阶段验证对象是上述新结论与五份协调文档，不重建产品、不重新解释旧失败。检查存量证据索引中的五件原件 SHA-256 和长度，直接从两帧计算矩形交集；文档检查严格 UTF-8、相对链接、机器路径卫生，复用 `scripts/check.ps1` 的原空白/冲突和凭据扫描块检查工作树与 index。检查脚本和摘要仅保存在忽略的 `.checks/window-source-admission-20261105/`。

实际检查 exit 0 / PASS：五份文档、120 个相对链接、原索引及五件成员的长度/哈希均匹配，两帧各两处交集均为 43×210；原工作树/index 空白与凭据扫描块通过。独立交付复核无阻断性问题；未将来源探索扩大为可运行 producer、隐藏 IME 或设备许可。仅五份文档变更，没有产品源码/合同变更。

源码两路调查及主 A 整合没有发现未知类型/IME 能力升级缺陷；完整产品门沿用未变状态，不称重新跑过。本阶段未证明 ROM 截图、持续绑定、自动 pane、完整坐标变换、严格同代或确认卡 safe-area。T-L1/P0/execution 仍未通过，已消费设备轮不重跑。
