# C1b 首次真机运行：vivo 安全中心撤销探针无障碍服务（2026-10-09）

> 结论：C1b 简单 runner 已在 PA2553 / Android 16 上走通构建、安装与就绪前全部步骤，但探针无障碍服务
> 每次开启后数秒内被 vivo 安全中心（`com.vivo.safecenter`）撤销，采集未执行。阻塞在设备安全策略，
> 不在 runner 或探针代码。下一步见 [backlog §4](../backlog.md)。

## 已确认的事实

- runner 前置全部满足：单设备、横屏 2800×1968、微信“应用多窗”在前台、键盘收起、HEAD clean。
- 撤销者：`dumpsys settings` 显示 `enabled_accessibility_services` 每次被 `pkg:com.vivo.safecenter` 改写，探针被移出；
  日志无原因记录。探针自身无崩溃、无 `disableSelf`。
- 服务能连上：探针自报 `a11y_service_ready=true` 的窗口最长约数分钟（一次，原因不明），通常 1–9 秒。
  vivo 的 `dumpsys accessibility` 绑定列表不列出已连接的探针（runner 已改以探针自报为准，`b2bd3c9`）。
- 重装会让 vivo 解绑无障碍（runner 已在同一 APK 时跳过安装，`6675194`）。

## 官方资料

- vivo：Android 15 起限制侧载应用的无障碍等高敏权限，弹窗可“解除限制”（需验证机主）——
  [vivo FAQ](https://www.vivo.com.cn/service/questions/all?categoryId=170&questionId=1836)。本次按此解除后仍被撤。
- Google：受限设置只能在应用信息页解除，厂商须默认开启——
  [Restricted settings](https://support.google.com/android/answer/12623953?hl=en)。
- 未找到 vivo 关于“安全中心在允许/解除限制后仍撤销第三方无障碍”的官方说明。

## 未知与推断

  可能是在该策略生效前开启。未证实。
- 原因未知：唯一一次保持数分钟的就绪。
- 设备现状：平板上装着本地签名的 release 版探针（与 debug 版签名不同，回到 debug 版须先卸载）。
