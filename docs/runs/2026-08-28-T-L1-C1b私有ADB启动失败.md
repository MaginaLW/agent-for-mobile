proof 继续固定 numeric `127.0.0.1`。失败发生在 USB 初始化之前，因此没有加入无关的

## 2026-08-29 离线修复与失败证据

后续成功进入正常取证才把同一 identity 提升为 `run_id`。若 private ADB 在 `run_id` 分配前失败，runner
以 `run_id=null` 生成 closed `tablet-layout-c1b-attempt-failure/v1`，并在全部 cleanup 完成后才将单个
root-level attempt record 原子发布。失败仍只消耗原授权的一次 runner invocation，automatic retry 为 0。

stdout/stderr、PID、port、socket、argv、path 或 serial。它能让未来新授权失败可诊断，但不会倒填本次旧 run
缺失的证据。
