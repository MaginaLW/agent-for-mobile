## 实现与审查

- 新组件只存在于 gateway debug 源集及 testDebug。端口显式接收服务身份原引用，Android adapter 在 SDK 调用前核对 `===`；状态对象、回执和 toString 不输出原生窗口 ID、服务对象或异常内容。
- 每个组件最多一次请求，显式操作超时不作为视觉 TTL；取消、超时、已知服务替换和异常均不能复活终态。同步 scheduler、同步平台回调、并发取消及消费者异常均有反例。已提交发起点后的取消不能撤回平台请求，迟到结果仍须清理。
- 成功回调仅借用有限元数据，不输出图像；借用结束时尝试关闭 buffer。close 是幂等契约，避免为去重保留无界历史引用；关闭异常报告失败/结果未知。取消或超时回执不证明尚未到达的 buffer 已清理，后续回调仍独立执行关闭尝试。
- 主审修复三处边界：adapter 固定服务与生命周期观测服务须显式关联；异步 metadata setup 普通异常在交付前清理并通知闭合失败，不能只等超时；start 依赖及回调抛 Error 时先冻结终态再重抛，不吞 fatal。
- 独立源码审查通过，没有 Provider/MCP/Activity/manifest 接线或 C1b APK source allowlist 扩展。现有 release absence 门补充 visionprobe 包检查，C1b 产物仍由原精确类白名单限制。
