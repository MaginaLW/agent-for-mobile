候选分支为 `codex/c1b-start-rejections`，固定完整 SHA：`e673e995579731fa2f2b7a723eabc6ecf6a3a2a3`；已推送 `origin/codex/c1b-start-rejections`，仍隔离，未合 main。此前 `51fe4ea848ed17f6cb0c033ef295f107bb328b41` 和已消费 run 保持冻结。

- controller 只保存最近一次精确 run_id/nonce 的 ABSENT 启动拒绝，单槽、有界，不缓存成功；status/capture/result/abort 优先同 key 的真实 active 或终态，再读拒绝槽，否则保持 session_not_found。下一次 start、rejectStart、shutdown 清除旧槽。
- 保留 session_busy 未消费新身份、replay ledger 容量和复用约束；不替换另一 active，不添加后台重试，不放行采帧。
