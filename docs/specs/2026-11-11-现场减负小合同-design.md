# 现场减负：现有能力与最小合同

日期：2026-11-11。承接[减少人工介入 §10 批次 5](2026-11-11-减少人工介入总体思路-design.md#102-按减少人工的收益排期)。源码核对基线 `3e93d9389f0e3fb9c8d0531587ca3f3e91d979d9`，实施分支 `codex/reduce-manual-offline`；本文只完成离线核定与合同准备，没有连接设备、构建、安装、改设置、创建运行卡或新增 C 队列批次。

目标是让现场用户只做工具确实无法替代的确认，避免重复安装、重开已就绪权限、手工抄读状态和逐阶段询问。验收看一次实际任务前后少了哪些人工动作，不以新增权限或进程数量作为成果。当前 C 队列未清；以下小合同涉及真机行为的实施与验证，须在队列准入、固定候选及就位后的本轮许可成立后进行。已授权离线准备可独立推进，不占 C 批次；完整目标尚未完成，不能把本合同称作真机减负通过。

## 2. 所有现场小合同共用的边界

每份未来就位报告必须填实固定完整 SHA、APK SHA/公开证书、唯一设备与 user、初始状态、允许阶段、累计调用/读取预算、一次激活事件、必要现场等待与停止条件。未知值显示 UNKNOWN，不能用历史记录、模板生成成功或连接状态作通过。本文件未核定这些本轮值，所以不具备开跑条件。

- C 队列有未清批次时不新增待验批次；本文件只列可复用合同，不能据此排队或开跑。每个实际行为批次至多 2–3 项改动，碰同一确认/布局面时仍须能独立归因。
- 就位后一次许可可以列清身份核对、准备、读回和有限验证的阶段链；已覆盖前置成功后连续执行，不逐阶段重问。候选、设备、制品、来源、目的地或预算改变不继承旧许可。
- 安装、权限、设置和 IME 切换都是写入，必须在该份许可中单列；危险动作继续由现场设备端可见确认卡决定。代码或 PC 输入不替代它，不自点 overlay。
- 失败即冻结当前轮、保存精确阶段/原因与 cleanup 结果，不自动恢复权限、换通道或重试。只有事先列入许可的独立后验/恢复分支能执行；不能以“恢复原状”为由临时取得额外写入权。
- 安装前仍提醒现场用户。安装确认等待不设自动超时，父层也不得截断；读取/就绪/采帧的次数和时限仍受限。A10 只允许事先单独覆盖的有限独立后验，不能追溯解冻旧轮或自动再安装。
- 日志、装包清单、权限与可识别设备状态留本地忽略目录；tracked 记录仅保留必要脱敏事实。凭据、真实账号/输入内容与原始图像不进入合同或台账草稿。

|---|---|---|---|---|
| F1 就绪复用与临时保屏 | 首先只读复用现有开发态配置；确实会熄屏且任务需要时，才增加一次临时保屏及对应恢复 | 固定候选/设备；读取 awake、keyguard、原 `stayon`/熄屏值和现有权限。临时写哪些键、具体值及一次恢复须逐项列入许可，不默认修改持久 ADB 授权时限 | 前读 → 已匹配项不写 → 获准的一项临时设置 → 读回 → 有界任务期间复核 → 授权内恢复与读回。keyguard 锁定/未知即停，不自动解锁 | 仅恢复本轮实际改变的键，不能覆盖用户中途改动；恢复失败记 UNKNOWN/FAIL。验收是用户无需反复唤醒/抄状态，不能只看写命令 exit 0 |
| F2 同包免重装与首次安装辅助 | 复用装包哈希跳过能力；确需安装时仅执行一次安装和明确覆盖的后验，修正拟复用旧入口的自动超时 | 固定 APK/公开证书、目标包/user、原装包与数据保留要求；签名私钥不在本合同内。只允许一次安装，不含卸载、换包或重签 | 本地制品身份 → 装包 SHA/证书核定 → 同包直接跳过；不匹配时仅在新安装许可内安装 → 安装结果及身份后验 → 就绪读回。旧入口须证明安装及父层不会自动截断现场确认等待 | 证书不匹配或身份未知即停，不卸载“修复”；安装效果未知保留 UNKNOWN，只有预先覆盖的独立后验可继续。节省是同包轮不再安装、用户不重开已有权限；ROM 必须的首次确认仍保留 |
| F3 既有 IME 的单次切换、合成输入与恢复 | 不重建 IME，先用现有 shell 白名单启用/切换能力及 `ImeBridge`；不为此先接 Shizuku 或新增 app 特权 | 固定包/IME component、获准合成靶标/输入框、固定非敏感短文本、原默认/启用 IME；一次 enable/set 和原状恢复单列。当前清单没有 `WRITE_SECURE_SETTINGS`，不能假定 app 已具自行切换权限 | 保存原状 → 仅补必要启用/切换 → 默认 IME 读回 → 当前输入会话的 package/id/connected 与目标复核 → 经现有安全门输入 → 内容/目标后验 → 恢复并读回。零 UI 的 visible=false 不作失败或隐藏证明 | 不按 Enter、不点击发送、不换另一输入通道重试失败危险动作；会话/目标未知即停。只恢复本轮改变项，不移除原已有输入法。节省是用户不逐轮手切输入法或修正合成文本；平板真实微信仍须自身前置与证据 |

## 4. 实施前应完成的离线准备与停止点

1. 对选中的一个小合同复用既有 runner、设备锁、身份核对与台账接口，先用模拟输入证明：无许可不进入写入、未知值不通过、单次失败不重试、恢复仅处理本轮改动。不得为这一步新建通用权限引擎。
2. 若复用旧 P0 安装入口，先修正其 120 秒自动截断并验证父层等待；不能只更新文档，或用 C1b 的同类通过结果替代受影响入口。
3. 对新增行为固定干净完整 SHA，完成其适用离线门与隔离制品/签名身份核定后，A 才能把**具体剩余人工与读回链**呈现到未来就位报告。原有 debug/release、ROM 与设备证据各自保留原范围。
4. C 队列准入、唯一现场与本轮许可任何一项未满足，就停在离线准备。已消费 S01–S05/C1b/P0 轮次不重新激活，不为“补经验”额外连接设备。

实际 run 沿用现有记录，列“准备前人工动作 → 工具已完成且有后验的动作 → 仍需用户的动作”，分别记录本人确认、系统读回和未知项。没有前后真实链路时不填节省百分比、不把本合同标作已验收。
