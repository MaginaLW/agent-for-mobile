# 未分类窗口完整保留

起点 `02af9ee15d89c1383b4f93f33d0cc7949614270c`，开发分支 `codex/c1b-unknown-types`。依据是[前轮两帧真实 -1 诊断](../runs/2026-11-05-窗口类型诊断真机采集.md)，不是窗口身份或 ROM 内部路径的推断。

## 可观察结果与边界

成功读取 Android Int 类型后，保留其 signed Int32 原值和通过后续校验的窗口壳，不再因项目原 `0..255` 范围而丢弃。已知 1–7 映射不变，其余使用既有 `unknown`；不特判 -1，不把未知窗口猜作系统窗、IME、应用窗或可忽略窗口。

在无枚举/容量/后续字段失败时，包含 unknown 的清单可以没有漏存（windows_truncated=false），但类型清单仍未确定。现有 unknown 安全门继续阻断焦点推断、IME 隐藏证明及完整应用拓扑；unknown 不进入应用 pane、标题匹配和语义子树投影。微信 opaque、目标会话/区域与 P0 门不由本次解决。

类型 getter 仍只读一次。原来在范围门停止的窗口现在继续原有 shell/root 读取，实际读取次数可能增加；display/layer/touchable/active/focused/id 等失败继续按原顺序短路并计数，不承诺真机必然保存全部五项。不新增截图、OCR、设置写入、权限或动作路径，不补旧轮、不重跑已消费运行。

## 成对版本与消费者

- 新 observation：`tablet-layout-observation/c1b-v2`。唯一数据域扩展是 platform_type_code 从 0..255 扩为 signed Int32；其余时间、绑定、隐私、安全常量与语义门沿用。旧 c1b-v1 schema、公开 validator 默认、离线门及 fixtures 继续按原范围解释。
- 新封套：`tablet-c1b-inventory-result/v3`。保留帧字段、12 个首次停止键及 rejected_type_code_counts 字段，但本版强制 window_type_invalid 首停为 0、拒绝类型表为空；成功 Int32 没有范围拒绝，原值在窗口中直接保留，无需另增聚合表。getter 异常仍记 window_type_read_failed。
- observation 的同名诊断 reason `window_type_invalid` 继续表示 unknown 或错误映射；它与外层“丢弃首停次数”含义不同，不能相互恢复。未知值可以合同有效而能力仍阻断；不顺带改变旧诊断 reason 的 fatal 分类。
- 当前 runner 只接受新封套和新 inner，落盘新版本文件名，拒绝旧版本或混搭。`tablet-c1b-run/v2` 收据形状不变，以 result_schema 区分封套版本；原始 observation、T0 和 SHA 绑定顺序不变。
- PowerShell 共享现有语义内核，通过显式固定版本参数和两个公开入口选择 schema；不临时改全局 schema 变量，不复制整套 validator，也不让新入口放宽旧入口。

## 串行链与独立工作

先固定本设计；Kotlin producer 与 PowerShell contract/consumer 两组并行，A 独立修改 runner/fake-ADB 接线和统一检查入口。A 整合后单实例跑针对性测试及完整门，再在一次交付边界独审。修复阻塞问题只复核受影响部分。最终固定新提交，补验 Android 制品身份，归档本轮离线结果和后续真机准入条件，提交并普通推送；不自动合 main。

写入归属：producer 仅 app 下 model/probe/controller 与相关 JVM tests；consumer 仅合同、validator、inventory parser 及其离线 tests；A 管理 runner、runner tests、check、设计/状态/经验与构建调度。独立研究/审查只读，不碰设备或共享重型检查。

## 验收

最小离线链路使用含 -1/Int32 两端/256 的 fake 平台窗口：单次 getter → 原值保留及 unknown → v2 JSON → v3 封套 → runner 原字节落盘 → 合同有效且 topology/focus/IME/执行能力保持阻断。已知 1–7、0/99/255、重复未知值也覆盖；未知后续字段失败、getter 异常、枚举失败、容量和计数守恒必须可区分。

消费者反例包括 Int32 域外/非整数、错误映射的能力提升、非空拒绝表/非零类型首停、新旧 inner/envelope 混搭、共载版本污染；保留原隐私、T0/producer/帧绑定、失败留证及不重采反例。旧 v1 门保持有效。Kotlin/接口变化触发项目完整离线门、Android JVM/Lint/构建与只读制品 proof；本阶段不使用真实签名密钥或设备。
