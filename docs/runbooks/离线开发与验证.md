# 无真机开发与验证

无设备时可做脚本回归、纯 Kotlin/JVM 单测、Android Lint、APK 构建与静态检查，但不替代确认卡、ROM 行为、微信落地页与平板布局的真机验收。
当前待办与候选见 [STATUS](../../STATUS.md) 和 [backlog](../backlog.md)。

## 一键检查

在仓库目录用项目钉定的 PowerShell（当前 7.6.5）运行：

```powershell
& '<repos-root>/_toolchain/powershell-7.6.5/pwsh.exe' -NoProfile -File scripts/check.ps1
```

- 脚本要求 7.5 以上，旧版本在正文执行前拒绝；只看退出码不能证明检查跑过。
- 先核对输出中的仓库路径，再看末尾汇总；完整日志在被忽略的 `.checks/`。
- `-SkipGradle` 只用于纯脚本迭代，结果会标记 Kotlin/Android 未验证。
- 完整发布或真机候选必须跑全量门，专项检查不能冒充。用例/套件数以本轮实际汇总为准。
- 改派单提示词或任务模板时，验证要覆盖真实组装和配置消费路径，不能只看模板文本。

## 环境前置

Windows 须允许创建符号链接（开启开发者模式，或用具备该特权的终端），C1b observation 离线测试的目录链接反例才会真正运行；脚本不改系统设置。
子套件可记录 skip，但聚合门拒绝把 skip 记为通过。

## 排障

长输出（构建日志、logcat）先落盘，再检索或尾读。
同一现象两轮未定位，下一轮前先查官方资料并设计单变量实验，不要接着调参数。

## 离线边界

- `dispatch -Confirm` 的边界以[执行 harness spec §5.2](../specs/2026-07-17-执行harness-design.md)为准：gateway 的 `RESUME` 只恢复尚未调用危险工具的纯前置交互，不是危险动作批准；mobile `-Confirm` 没有独立人控批准通道，一律拒绝，不得改 `-Executor` 迁移旧件。
- 暂停件解析：字段不分大小写且不得重复，头部非空行须为 `key: value`，显式 `consumed` 不得为空，只有规范 `leg=1` 能进第二腿，路径按字面读取。
- 语义意图新模块可先做纯单测；生产接线会改变真机行为，须按 backlog 排队验收。
- 分享落地 activity 白名单必须来自真机观测；没有观测就保持空值，不凭类名填充。
