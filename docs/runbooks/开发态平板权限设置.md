# 开发态平板权限设置（PA2553 / Android 16）

> 仅限隔离开发平板。目标是让 ADB/Shizuku 主通道、无障碍辅助和常用调试权限尽快可用，减少人工开关；**不用于生产、真机验收或 T-L1/P0 证据**。正式验收仍按 [C1b 规程](T-L1-tablet-c1b.md)和 [backlog §7.3](../backlog.md#73-开跑条件)执行。

当前设备只读检查见 [2026-11-09 开发态平板权限只读检查](../runs/2026-11-09-开发态平板权限只读检查.md)。设备为 PA2553 / Android 16 / `DPD2437C_A_16.1.10.7.W10`；安全中心 6.2.1.3 活跃；user 0 当前没有项目包；USB ADB 可用；无 root。

## 1. 需要增加的权限/设置

| 类别 | 项目 | 当前 | 开发态建议 |
|---|---|---|---|
| 运行时 | `POST_NOTIFICATIONS` | 未安装，未授予 | `pm grant` |
| 运行时 | `READ_MEDIA_IMAGES` | 未安装，未授予 | 需要图片导入时 `pm grant` |
| 运行时 | `BLUETOOTH_CONNECT` | 未安装，未授予 | 需要蓝牙工具时 `pm grant` |
| 特殊访问 | `SYSTEM_ALERT_WINDOW` | 未安装，未授予 | `appops` 或设置页 |
| 无障碍 | `GatewayA11yService` | 当前只有 vivo 输入法服务 | 追加 enabled 列表或设置页 |
| 后台 | 电池白名单 / standby bucket | 未安装 | `dumpsys deviceidle` / `am set-standby-bucket` |
| 后台 | 后台高耗电 / 自启动 / 后台弹出界面 / 锁最近任务 | 未安装 | vivo 设置页手动 |
| 系统 | `adb_allowed_connection_time` | `604800000`（7 天） | 改为 `0` |
| 系统 | 充电常亮 / 屏幕超时 | 关闭 / 30 分钟 | 打开 / 拉长 |
| 系统 | 锁屏 | 未禁用 | 可选禁用（隔离机） |
| 硬解 | 安全中心 | 6.2.1.3 活跃 | 可选可逆禁用 |

APK 当前**没有声明** `WRITE_SECURE_SETTINGS`、`DUMP`、`GET_APP_OPS_STATS`、`PACKAGE_USAGE_STATS`、`QUERY_ALL_PACKAGES`。因此这些不能直接 `pm grant`：

- 不需要 App 自己执行时，全部走 ADB shell；
- 需要 App 内部执行时，在 `app/gateway/src/debug/AndroidManifest.xml` 增加 debug-only 的 `uses-permission`，重建后再授权；
- `DUMP` 目前在 debug provider 上只是调用方权限，不是网关自身权限，不要混淆。

## 2. 分工

| 事项 | A 可直接做 | 需要用户协助 |
|---|---|---|
| ADB 授权超时、常亮、屏幕超时 | 是 | 无 |
| 安装 debug APK | 执行 `adb install` | vivo 弹安装确认时点继续 |
| 运行时权限、悬浮窗、电池/待机 | 是 | 无 |
| 允许受限设置 | 先试 `appops` | 失败时走应用信息三点菜单 |
| 无障碍启用 | 先试 `settings put` | 被拦或需手动确认时开开关 |
| 后台高耗电、自启动、后台弹出界面、锁最近任务 | 不能完全代做 | 需要用户在设置/i管家/最近任务操作 |
| 禁用安全中心 | 执行命令 | 需要用户确认风险 |
| 关闭锁屏、关闭安装校验 | 执行命令 | 需要用户确认；可能需输入锁屏密码 |
| 无线调试配对 | 不能 | 打开无线调试、提供配对码 |
| 测试账号登录 | 不能 | 微信/支付宝等账号由用户处理 |
| 重启后解锁 | 执行重启 | 需要用户解锁（除非先关锁屏） |
| root / Device Owner | 不能 | 需要解锁/刷机或恢复出厂；当前无 root |

## 3. 设置步骤

以下命令是开发态建议命令。`<adb>` 使用固定 SDK 路径，例如 `<SDK>\platform-tools\adb.exe`；`<pkg>` 为 `dev.magina.gateway`。

### 3.1 ADB 长期可用与常亮

```text
<adb> shell settings put global adb_allowed_connection_time 0
<adb> shell settings get global adb_allowed_connection_time
<adb> shell settings put global stay_on_while_plugged_in 7
<adb> shell settings put system screen_off_timeout 2147483647
<adb> shell settings get global stay_on_while_plugged_in
<adb> shell settings get system screen_off_timeout
```

期望读回 `0`、`7` 和较大的超时值。若 vivo 忽略这些键，改用开发者选项里的“停用 ADB 授权超时”和“充电时保持唤醒”。

可选关闭锁屏（隔离机）：

```text
<adb> shell locksettings set-disabled true
```

恢复：

```text
<adb> shell locksettings set-disabled false
```

### 3.2 安装 debug APK

```text
<adb> install -r -g --user 0 app\gateway\build\outputs\apk\debug\gateway-debug.apk
<adb> shell pm list packages | grep dev.magina.gateway
<adb> shell dumpsys package dev.magina.gateway | grep -E "versionName|targetSdk|installerPackageName"
```

vivo 可能弹出安装确认页；`adb install` 返回成功前不要拔线。安装后如果包不存在，不要反复重试，先看平板是否停在安装页。

### 3.3 受限设置、运行时权限和悬浮窗

先在平板上：

```text
设置 → 应用 → 执行网关 → 右上角三点 → 允许受限制的设置
```

或：

```text
<adb> shell appops set dev.magina.gateway ACCESS_RESTRICTED_SETTINGS allow
```

然后：

```text
<adb> shell pm grant dev.magina.gateway android.permission.POST_NOTIFICATIONS
<adb> shell pm grant dev.magina.gateway android.permission.READ_MEDIA_IMAGES
<adb> shell pm grant dev.magina.gateway android.permission.BLUETOOTH_CONNECT
<adb> shell appops set dev.magina.gateway SYSTEM_ALERT_WINDOW allow
```

### 3.4 无障碍

先读当前列表，保留 vivo 输入法条目：

```text
<adb> shell settings get secure enabled_accessibility_services
```

当前基线为：

```text
com.vivo.ai.ime.pad/com.vivo.ai.ime.sticker.rtpicture.accessibility.AutoSendImageService
```

追加网关服务：

```text
<adb> shell settings put secure enabled_accessibility_services "com.vivo.ai.ime.pad/com.vivo.ai.ime.sticker.rtpicture.accessibility.AutoSendImageService:dev.magina.gateway/dev.magina.gateway.a11y.GatewayA11yService"
<adb> shell settings put secure accessibility_enabled 1
<adb> shell appops set dev.magina.gateway BIND_ACCESSIBILITY_SERVICE allow
```

核对：

```text
<adb> shell settings get secure enabled_accessibility_services
```

如果 `adb install -r` 后服务不重绑，先清空再写回；这会短暂移除其他无障碍服务，只适合开发平板：

```text
<adb> shell settings delete secure enabled_accessibility_services
<adb> shell settings put secure enabled_accessibility_services "com.vivo.ai.ime.pad/com.vivo.ai.ime.sticker.rtpicture.accessibility.AutoSendImageService:dev.magina.gateway/dev.magina.gateway.a11y.GatewayA11yService"
<adb> shell settings put secure accessibility_enabled 1
```

不要用 `uiautomator dump` 验证无障碍绑定；它可能抑制现有服务。用 enabled 列表、应用日志和实际读树/点击分别判断。

### 3.5 vivo 后台设置

ADB 可做：

```text
<adb> shell dumpsys deviceidle whitelist +dev.magina.gateway
<adb> shell am set-standby-bucket dev.magina.gateway active
<adb> shell appops set dev.magina.gateway RUN_ANY_IN_BACKGROUND allow
```

用户需要在平板上确认：

1. 设置 → 电池 → 后台耗电管理 → 执行网关 → 允许后台高耗电。
2. 设置/ i管家 → 应用管理 → 权限管理 → 自启动 → 执行网关 → 开。
3. 设置 → 应用 → 执行网关 → 电池 → 关闭“如果未使用则暂停应用活动”。
4. 应用权限 → 后台弹出界面 → 允许。
5. 最近任务 → 执行网关卡片上锁。

### 3.6 验证

```text
<adb> shell input keyevent KEYCODE_WAKEUP
<adb> shell input tap 500 500
<adb> exec-out screencap -p > screen.png
<adb> shell uiautomator dump /sdcard/ui.xml
<adb> shell dumpsys window | grep -E "mCurrentFocus|mFocusedApp"
```

`input` 报 `SecurityException` 时检查 vivo 的“USB 模拟点击/安全调试”；本机当前 `persist.sys.adb.simulate.ic=true`。

无障碍撤销观察：分别打开系统设置、微信、QQ，各停留 20 秒，回到桌面后读：

```text
<adb> shell settings get secure enabled_accessibility_services
```

服务消失即说明安全中心仍在撤销；服务保留只说明本次窗口未命中，不证明长期绑定。

## 4. 如果无障碍仍被撤销

先试可逆禁用安全中心：

```text
<adb> shell pm disable-user --user 0 com.vivo.safecenter
<adb> shell pm list packages -d | grep vivo.safecenter
```

恢复：

```text
<adb> shell pm enable com.vivo.safecenter
```

建议先完成安装和首轮授权，再禁用安全中心；禁用后可能影响安装确认、权限弹窗或安全功能。不要直接卸载；`pm disable-user` 可逆。若命令返回 `SecurityException` 或 `Package ... is protected`，当前无 root，不要继续刷机；改用 ADB 主通道。

## 5. 验证后的预期与限制

会明显改善：自动启动、点击/滑动、截图、切换 App、读取系统状态、长链路中断后重连。

仍可能存在：

- 微信 `uiautomator dump` 空壳，需要截图 + 视觉/OCR 兜底；
- `FLAG_SECURE` 窗口截图黑屏；
- 首次安装确认、受限设置或无障碍手动兜底；
- 重启后无线 ADB/Shizuku 重连、锁屏解锁；
- 安全中心未禁用时的 1–20 秒撤销；
- 第三方 App 自身登录、支付、风控限制。

## 7. 依据

- [Android AccessibilityService](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)：无障碍只能由用户在设置中显式开启。
- [vivo 官方 FAQ](https://www.vivo.com.cn/service/questions/all?categoryId=170&questionId=1836)：Android 15+ 侧载应用高敏权限的“解除限制”流程。
- [Android ADB](https://developer.android.com/tools/adb)：USB/无线调试、配对与授权。
- [AOSP `adb_allowed_connection_time`](https://android.googlesource.com/platform/frameworks/base/+/6d408b5bf20431ac41ed039f2ad192b150c02eff/core/java/android/provider/Settings.java)：默认 7 天授权窗口。
- [DSH-APP/DSHA #183](https://github.com/DSH-APP/DSHA/issues/183)：vivo Android 16 设置/QQ/微信触发无障碍不可用，建议 ADB/Shizuku 主通道。
- [droidrun/mobilerun-portal #142](https://github.com/droidrun/mobilerun-portal/issues/142)：vivo 微信 `uiautomator dump` 可能为空。
