### 2. 通道 smoke（PC 侧，不经大脑，零 token）

```powershell
adb forward tcp:8848 tcp:8848
$t = "<主界面复制的 token>"
$H = @{ Authorization = "Bearer $t"; "Content-Type" = "application/json" }
# 连通 + 工具面
irm http://127.0.0.1:8848/health
irm http://127.0.0.1:8848/mcp -Method Post -Headers $H -Body '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
# 逐通道各点一发（按通道成本从低到高）：
# L1: device_info / system_get_state(bluetooth) / media_query(screenshot)
irm http://127.0.0.1:8848/mcp -Method Post -Headers $H -Body '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"system_get_state","arguments":{"key":"bluetooth"}}}'
# L2: open_uri(xhsdiscover://search/result?keyword=%E6%B5%8B%E8%AF%95) → 看 foreground_verified
# L4: ui_snapshot（设置页）→ ui_find(text=蓝牙) → ui_action(click) → 树空 app 看 note 字段
# 输入链: 微信文传助手 type_text("中文 空格 测试", mode=replace) → 看 channel/readback/verified
# L6: screen_capture(reason=unknown_page) → 确认 MCP image content 回图；连发两次看 E_RATE_LIMITED
# 确认层: ui_action 点一个含「删除」的控件 → 悬浮窗卡片应弹出；拒绝 → E_BLOCKED
```
