# 运行复核草稿

`scripts/prepare-run-review.ps1` 从已有 `tablet-c1b-run/v1` 或 `v2` 的 `run.json` 生成复核材料，减少人工抄写。输入只读，输出只允许本仓库 `.checks/` 子目录；重复输出拒绝覆盖。工具不连接设备、不读 keystore 私钥、不签名、安装、写真实台账或发送询问。

用钉定的 PowerShell 运行：

```powershell
& './toolchain/powershell-7.6.5/pwsh.exe' -NoProfile -File scripts/prepare-run-review.ps1 `
  -ManifestPath '<已有证据目录>/tablet-layout-c1b/run.json' `
  -OutputDirectory '.checks/reduce-manual-20261111/review-drafts/<run-id>'
```

输出 `review.json`、`readiness.md`、`ask.md`、`ledger-draft.csv`、`run-draft.md`。就位与 ask 草稿复用同份身份摘要，明确原 manifest SHA、固定 commit/producer/APK/公开证书以及已检查的显式期望；单项 matched 不代表整体就绪，APK 或证书未检查仍显示 UNKNOWN。CSV 复用既有 17 列和公式中和规则；只生成带 DRAFT_ONLY 标记的草稿，不可直接追加真实台账。原 manifest 的 outcome 与 runner exit 分别保留；只有 `passed + 0` 映射 success，`failed + 非零` 映射 fail，其余 UNKNOWN。缺失 cleanup、模型、成本、耗时及外层退出码均保持 UNKNOWN，不推断为成功或零。

身份预检可选 `-ExpectedCommitSha`、`-ApkPath`、`-ExpectedApkSha256`；APK 将实际计算 SHA-256，并与 manifest 及显式期望比较。需要证书时另给 `-ApkSignerPath '<Android SDK>/build-tools/<version>/apksigner.bat' -ExpectedCertificateSha256 '<64 位证书 SHA-256>'`，仅运行 `verify --print-certs`，只接受唯一 signer。显式失配、缺少所需实读证据、签名无效或多个 signer 均输出 blocked 并 exit 2；其他输入/落盘错误 exit 1。单项 matched 只说明列出的检查匹配，其余字段仍可 UNKNOWN，永不等于设备可开跑。

未来范围可用 `-ScopePath '<本地范围 JSON>'` 填模板；不提供则所有本轮现场与预算字段 UNKNOWN。示例只描述提案，不授予运行许可：

```json
{
  "schema": "run-review-scope/v1",
  "request_id": "A01",
  "device_evidence": "本轮唯一设备证据待核对",
  "pose_evidence": "本轮姿态证据待核对",
  "windows_evidence": "本轮窗口证据待核对",
  "ime_evidence": "本轮 IME 证据待核对",
  "stages": ["身份与就绪核验", "前置通过后一轮采集"],
  "max_sdk_calls": 12,
  "read_budget_seconds": 140,
  "activation": "现场明确批准且前置通过后一次激活",
  "latest_activation": "本轮核定，含时区",
  "stop_conditions": ["任一阶段失败即冻结，不重试"]
}
```

A 必须核对固定完整 SHA、制品、当前现场、阶段、累计预算与停止条件；历史 manifest 不能填充当前就位，不因生成报告或身份 matched 自动开跑。已有许可覆盖的阶段不重复询问；确需新许可时，核对现行 `approval-feedback` 后再发 `ask.md`，按会话实际编号替换示例。模板保留可省略评分的含义，评分不授予未来权限。危险动作仍由设备端可见确认卡批准；安装等待不自动超时，累计读取预算不包含安装等待。

专项：`./toolchain/powershell-7.6.5/pwsh.exe -NoProfile -File scripts/tests/prepare-run-review-offline.ps1`。测试全部用区内隔离材料，真实成功与失败的演示产物留在忽略目录，不能把离线结果称作新真机验收。
