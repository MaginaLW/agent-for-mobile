# App 实测特性（微信 / 小红书 / 京东）

> 整理自 M0 实测（2026-07-16）。原始记录：[docs/runs/2026-07-16-M0.md](../runs/2026-07-16-M0.md)。内容多了按 app 拆册。

## 微信

- **无障碍树恒空**：`mobile_list_elements_on_screen` 在微信内始终返回空，只能截图+视觉定位 → 微信类任务是纯视觉任务，成本高一个数量级（见 [cost.md](cost.md)）。
- M0 发生 2 次误触（点开联系人资料页、点开聊天内敏感 PDF），均立即退出无改动。成因：键盘弹出坐标错位 + 视觉定位偏差。→ **M1 需求：敏感对话/文件黑名单、点击前二次校验、键盘状态感知。**
- 发送闭环可行（ASCII 消息实测成功）；中文输入卡在 devicekit 剪贴板机制（见 [devices.md](devices.md)）。

## 小红书

- **深链一步顶十步**：`xhsdiscover://search/result?keyword=<urlencoded>` 直达搜索结果，完全绕开「点搜索框+中文输入」（见 [deeplinks.md](deeplinks.md)）。
- 返回列表后 feed 位置精准恢复：「进详情→返回→进下一条」多步模式可行。
- ⚠️ 详情页图片区**双击=点赞**，agent 必须单击（只读纪律）。

## 京东

- `uiautomator dump` 超时（重动画首页），M0 全程视觉定位完成。
- 全程无风控/无验证码：USB 调试 + 注入未被电商 app 拦截；开屏无广告（可能因老用户/monkey 直接启动）。
- 物流路径：京东 → 我的 → 全部订单 → 订单详情 → 更多 → 查看物流。
- ⚠️ 「更多」弹出菜单里**「删除订单」与「查看物流」相邻**——M1 确认层的危险控件识别要覆盖弹出菜单场景。
