# 成本模型与实测校准

> 原估来自[方向一设计说明 §5](../specs/2026-07-16-方向一-手机执行器与订阅大脑-design.md)；实测来自 M0（2026-07-16，Sonnet 5，headless JSON 精确计量）。

## 原估 vs 实测

| | 原估 | M0 实测 |
|---|---|---|
| 单任务成本 | $0.15–0.5（10–15 步） | a11y/深链型便宜；**纯视觉型 $3+/任务** |
| Pro $20/月容量 | ≈ 40–130 任务 | **≈ 6 个微信级纯视觉任务** |

实测明细（headless JSON）：任务 2 微信发消息 $6.44 / 186 轮（含中文输入反复排障）；任务 4 截图发微信 $1.26 / 35 轮；预检 $0.76。合计 ≈ $8.5。任务 1/3/5（设置/小红书/京东，a11y 或深链可用）由主会话代驾未单独计量，但明显便宜。

## 结论（M0 发现 #12，可行性级别）

- 纯视觉任务比原估**高一个数量级**——每轮都带截图是成本主因（微信 a11y 树为空所致，见 [apps.md](apps.md)）。
- **深链库、宏回放、a11y 树优先不是优化项，是可行性前提。**
- 重度使用需 Max 档订阅，或把 grounding 类子任务路由到便宜模型（Haiku）。
- 降本杠杆排序：宏回放（零 token）> 深链（省整段导航）> a11y 树（比截图便宜一个量级）> 提示缓存 > 模型路由。
