# 成本模型与实测校准

> 原估来自[方向一设计说明 §5](../../specs/2026-07-16-方向一-手机执行器与订阅大脑-design.md)；实测来自 M0（2026-07-16，Sonnet 5，headless JSON 精确计量）。

## 原估 vs 实测

| | 原估 | M0 实测 |
|---|---|---|
| 单任务成本 | $0.15–0.5（10–15 步） | a11y/深链型便宜；**纯视觉型 $3+/任务** |
| Pro $20/月容量 | ≈ 40–130 任务 | **≈ 6 个微信级纯视觉任务** |

实测明细（headless JSON）：任务 2 微信发消息 $6.44 / 186 轮（含中文输入反复排障）；任务 4 截图发微信 $1.26 / 35 轮；预检 $0.76。合计 ≈ $8.5。任务 1/3/5（设置/小红书/京东，a11y 或深链可用）由主会话代驾未单独计量，但明显便宜。

## M0.5 harness 复测（2026-07-17，dispatch.ps1 + 站规 v1，台账 ledger.csv）

- 只读微任务（查蓝牙状态）：**$0.44 / 5 轮 / 22s**——a11y 直读设置首页摘要，未进子页。
- 任务 4 复测（截图发微信）：**$2.01 / 55 轮 / 305s，任务成功但触 $2 上限**，报告被截断在终点线。比 M0 基准（$1.26/35 轮）多烧的轮次：工具预热 ToolSearch ~5 轮 + 截图坐标缩放排障 ~8 轮 + 微信选图器回弹 ~10 轮。三项均已固化对策（站规 v2：设备号直供、批量预热、坐标换算；任务卡改走相册分享路径），下轮预期回落到 $1.3 上下。
- 预算护栏实测有效：$0.05 上限 2 轮即熔断（$0.077 停）；$2 上限恰好兜住跑偏任务。
- 结论不变：纯视觉（微信类）仍贵一个量级；护栏默认 $2 合理。

## Codex 订阅通道计量边界（2026-08-28）

- `dispatch.ps1 -Brain codex -Executor gateway` 走 ChatGPT 订阅通道，CLI JSONL 提供 token usage，
  但不提供可写入台账的单次 API 美元成本；因此 `cost_usd` 留空。
- `-MaxBudgetUsd` 只传给 Claude CLI，且只接受大于 0 的有限数字。Codex 当前没有等价的美元硬上限，DryRun、提示词与结果摘要必须显示
  “订阅通道/无 API 硬上限”，不能把默认 `$2` 冒充为 Codex 成本护栏。
- Codex 仍受 1–60 分钟墙钟、整棵 Job 进程树归零，以及 stdout 16 MiB / stderr 4 MiB 的机械上限约束。

## 结论（M0 发现 #12，可行性级别）

- 纯视觉任务比原估**高一个数量级**——每轮都带截图是成本主因（微信 a11y 树为空所致，见 [../apps/wechat.md](../apps/wechat.md)）。
- **深链库、宏回放、a11y 树优先不是优化项，是可行性前提。**
- 重度使用需 Max 档订阅，或把 grounding 类子任务路由到便宜模型（Haiku）。
- 降本杠杆排序：宏回放（零 token）> 深链（省整段导航）> a11y 树（比截图便宜一个量级）> 提示缓存 > 模型路由。
